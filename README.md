## 📄 Project Overview
In paper manufacturing, maintaining optimal moisture levels is critical for product quality. This project processes sensor data to identify missing values, align timestamps, and detect deviations. It uses advanced statistical techniques and dimensionality reduction (PCA) to create a high-quality dataset for predictive quality monitoring.

This repository contains **6 key files** representing the two phases of the project (CIA 2 and CIA 3):

* **`CIA3 - (2460601) (Continuation of CIA 2).ipynb`** * *Phase 2 Code:* Covers Feature Engineering, PCA (Dimensionality Reduction), Visualization, and Data Integration (SQL/CSV export).

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SQLite3
* **Environment:** Jupyter Lab / Notebook

## 📊 Key Results
* **Data Cleaning:** Successfully imputed missing moisture values using linear interpolation.
* **Outlier Detection:** Identified deviations using Z-score analysis.
* **Dimensionality Reduction:** Used PCA to reduce 3 environmental variables (Moisture, Temp, Humidity) into 2 principal components, revealing distinct clusters for "Normal" vs "Deviation" batches.
